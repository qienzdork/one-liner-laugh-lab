# One-Liner Laugh Lab

A single short funny line answering the prompt: the excuse a robot vacuum gives after eating a sock. The vacuum doesn't apologise — it blames its job description.

`main.py` is a small deterministic program (stdlib only, no network, no randomness) that writes the line to `/output/entry.txt` by default, or to `$OUTPUT_PATH` when set.
